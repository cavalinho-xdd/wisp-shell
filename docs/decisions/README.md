# Decision records

One short file per decision that shapes the project and would be expensive to
revisit: what we chose, why, and what we gave up. Format after Michael
Nygard's *Documenting architecture decisions* (2011).

- Number files `NNNN-short-title.md`, never reuse a number.
- Don't edit a decided record; write a new one and mark the old one
  *Superseded by NNNN*.
- Copy `template.md` to start.
